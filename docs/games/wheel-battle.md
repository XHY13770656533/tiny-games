# 转盘大作战 · 策划案

> 状态：可玩  
> 游戏 id：`wheel-battle`  
> 路由：`/games/wheel-battle`  
> 目标平台：Tiny Games 纯前端（Vite + React + TypeScript + Canvas）  
> 参考模板：[`docs/vibe-coding/game-brief-template.md`](../vibe-coding/game-brief-template.md)

本文档是实现前的完整设计基线。后续 vibe coding 时以本文为准，优先落地「可玩闭环」，不要先做皮肤、剧情 CG 或联网排行。

## 游戏名称

**转盘大作战**

英文目录名：`wheel-battle`

一句话卖点：**战前自己组装转盘，战时只在关键窗口按下转动，局后用金币养成效果。**

它不是「幸运转盘」的换皮，也不是需要走位的雷霆战机。战场看起来仍是纵向空战，玩法更接近塔防：敌机按波次进攻，玩家战机自动开火、自动锁定，玩家不放置防御塔，只通过转盘做升级和强化。局与局之间用补给金币升级常用效果，形成轻养成。

---

## 游戏目标

玩家在进入战斗前装配好转盘，然后观看并干预一场自动空战：击落敌机积攒能量，能量满一次就获得一次可储存的转动机会。玩家要在合适的时机消耗这些机会，让护甲、维修、特殊炮弹在最需要的窗口生效，并在每一关末尾击败大 Boss。

通关目标：打完 3 关并击败最终 Boss「赤红母舰」。

单局追求：尽可能高的综合评分（击坠、漏敌少、Boss 速杀、剩余生命、剩余转动次数）。

跨局追求：攒补给金币，把喜欢的扇区升到 3 级，让同一套方案更稳、更高分。

## 体验定位

| 维度 | 选择 | 原因 |
| --- | --- | --- |
| 类型 | 自动塔防 + 转盘构筑 | 战场自己推进，玩家的操作是「何时强化」 |
| 难度 | 困难 | Boss 有预报窗口，乱转或囤到死都应受罚 |
| 单局时长 | 6–10 分钟 | 适合 Tiny Games，避免做成关卡编辑器 |
| 操作负担 | 极低 | 战斗中只有「转动」和「暂停」 |
| 随机性 | 有约束的随机 | 扇区大小 = 概率，转动时机 = 技术 |
| 失败惩罚 | 本关重开 | 不回退本局已解锁扇区；金币与升级跨局保留 |
| 养成 | 轻、局外 | 一局结束后发金币，只升级部分效果，不做成数值膨胀的放置游戏 |

玩家全程做三件事：

1. **机库**：用跨局金币升级已解锁的部分效果。
2. **整备**：组装转盘，决定这一局的概率。
3. **战斗**：选择时机转动，决定这一次强化落在哪一段战况上。

不需要走位、瞄准、放置防御塔或手动开火。

与现有游戏的边界：

- 相对 `lucky-wheel`：金币不在战斗里抽奖，只在局后进入机库养成；转盘奖励作用在自动战场。
- 相对 `breakout` / `mirror-flyer`：同属 Canvas 循环，但玩家输入不是位移，而是消耗转动次数。

## 核心玩法

- 操作方式：鼠标 / 触控点击「转动」；键盘 `Space` 也可转动；Canvas 只负责演播战场
- 胜利条件：第 3 关 Boss 生命降至 0
- 失败条件：基地生命降至 0
- 分数规则：击坠分 + Boss 阶段分 + 剩余生命加成 + 少漏敌加成；最高分写入 `localStorage`

### 主循环

```txt
机库：查看金币，升级部分效果
    → 整备：从已解锁图鉴里组装转盘（方案锁定）
    → 自动空战：敌机按波次进攻，战机自动开火
    → 击落敌机获得能量
    → 能量满 100：获得 1 次转动机会，能量清零并继续蓄力
    → 机会可叠加，玩家自行决定何时按下转动
    → 抽到的扇区立刻按当前升级等级改写战场
    → 清完波次后迎战 Boss
    → 击败 Boss 永久解锁新扇区，回到整备，再进入下一关
    → 胜利或失败结算：发补给金币，返回机库
```

战斗一旦开始，**不能再改扇区种类、大小或升级**。下一关开始前允许重新组装，因为新效果会解锁。升级只在机库进行，战斗中和整备滑杆里都不能花钱。

### 玩家的唯一战斗决策：何时转动

转动机会不是「满了就必须转」，而是可以存着。正确时机通常是：

- 下一波即将涌入，需要火力覆盖
- 基地残血，需要维修或护甲
- Boss 预报了高伤害技能，需要护盾、清屏或时缓
- 场上有护盾精英 / 双目标，需要穿甲或散射

错误时机通常是：

- 满血满甲时把维修转掉
- 场上没有敌弹时把清屏转掉
- 波次间隙把短时火力转掉
- 一直囤满 3 次机会，被 Boss 技能直接打死

## 战场规则（自动塔防式空战）

视觉仍用雷霆战机式纵向卷轴：星空、敌机、弹幕、关底 Boss。规则按塔防来，不按射击游戏来。

### 空间与镜头

- 纵向卷轴，背景星空缓慢下移。
- 坐标系归一化到 `0–100`（宽）× `0–100`（高），Canvas 只负责缩放绘制。
- 战场分 3 条航道：左 `x=22`、中 `x=50`、右 `x=78`。敌机沿航道推进，可在航道内小幅摆动，方便阅读。
- 玩家战机固定在画面下方中央 `x=50, y=86`，只做轻微悬停动画，**不能被玩家移动**。
- 底线 `y=92` 是基地防线。敌机越过底线视为漏敌，对基地造成撞击伤害后消失。
- 敌机从 `y < 0` 入场。

### 基地与战机

玩家操控的不是飞机走位，而是这座自动炮台。生命、护甲都挂在基地上。

| 属性 | 初始值 | 说明 |
| --- | --- | --- |
| 生命 | 100 | 归零即失败 |
| 护甲 | 0 / 上限 80 | 先扣护甲再扣生命；装甲升级后上限 90 / 100 |
| 锁定 | 自动 | 优先打最靠近底线的敌机，同距离打血量更高的 |
| 自动炮 | 每 220ms 1 发 | 射向当前锁定目标，伤害 8 |
| 特殊弹仓 | 空 | 由转盘装填，用完回到普通炮 |
| 覆盖 | 中路最稳 | 没有散射 / 导弹 / 无人机时，左右路输出偏低 |

受伤后有 350ms 无敌闪烁，避免同一串弹在单帧内把生命打空。无敌期间火力不停。

### 敌机

三类常规单位，全部由 `logic.ts` 的波次表生成，不在组件里手写刷新：

| 类型 | 生命 | 行为 | 漏敌伤害 | 能量掉落 | 击坠分 |
| --- | --- | --- | --- | --- | --- |
| 侦察机 `scout` | 12 | 单航道下压，偶尔对基地射 1 发 | 10 | 12 | 30 |
| 炮艇 `gunship` | 36 | 进入 y=28 后在航道内悬停射击，打完再推进 | 18 | 22 | 70 |
| 精英机 `elite` | 80 | 带小护盾，扇形 5 发；死亡必掉能量 | 28 | 40 | 150 |

刷新约束：

- 同屏敌机上限 10（Boss 战时上限 6 小兵 + 1 Boss）。
- 子弹同屏上限 80，超出时优先回收已飞出屏幕的敌弹。
- 第 1 关前 12 秒只出中路侦察机，用来教「看能量、等时机、按转动」。

### 碰撞与伤害来源

统一 AABB，但玩家没有位移，伤害来源只有两种：

- 玩家弹 × 敌机 / Boss：扣目标生命，玩家弹消失（穿甲弹除外）。
- 敌弹 × 基地：先扣护甲，再扣生命。
- 敌机越过底线：造成漏敌伤害，该敌机离场。
- 特殊弹「脉冲清屏」不是碰撞，而是范围效果函数。

没有「机体互撞需要躲开」。漏敌就是塔防里的漏怪。

### 能量与转动次数

能量和转动次数分开记账。

| 项目 | 规则 |
| --- | --- |
| 能量上限 | 100，满了立刻兑换，不卡条 |
| 兑换 | 能量每满 100，转动次数 +1，能量清零后继续累积溢出部分 |
| 次数上限 | 3。到 3 后能量仍可积，但满 100 不再加次数，改为 30% 转成分数 |
| 战斗节奏 | 能量满时战场不暂停、不强制转动 |
| 消耗 | 按一次「转动」只消耗 1 次机会 |
| 掉落 | 击毁当下直接入条，不做满地捡道具 |

HUD 始终显示：能量条、当前次数 `0/3`、以及「转动」按钮。次数 ≥ 1 时按钮可点；次数 = 0 时按钮灰掉。

转动动画约 1.1s。这一小段可以冻结算效果、让玩家看清指针，但 **不等待动画就不给攒能量**——动画结束后战场按原节奏继续。不要把整场战斗卡死在「必须先转完才能继续」。

## 转盘系统（本作成员差异点）

### 设计原则

1. **战前决定概率，战时决定时机。** 扇区越大，抽中越稳；按得越准，这发强化越值钱。
2. **战斗中方案锁定。** 不能临时把维修格改成清屏。
3. **全部扇区默认是正面效果。** 没有「空奖」「扣血」格。风险来自「转早了、转晚了、转在错误窗口」。
4. **不能把转盘做成只有一个超大格。** 用数量、单格上下限卡死极端解。
5. **效果要能立刻在战场上被看见。** 护甲出盾、维修出绿十字、特殊弹改弹道。

### 组装规则

组装只发生在战斗外：开局整备，以及每关 Boss 战后、进入下一关前。

| 约束 | 数值 |
| --- | --- |
| 扇区数量 | 最少 4，最多 7 |
| 单格权重 | 8–40 |
| 权重总和 | 必须等于 100 |
| 同类型 | 每种效果最多 1 格 |
| 未解锁效果 | 不可装配 |

操作：

- 从已解锁效果列表「加入扇区」
- 拖动滑杆改大小；实现时推荐：**改当前格，剩余权重按其他格原比例重分配**，保证总和恒为 100
- 提供「平均分配」「恢复推荐方案」两个快捷按钮
- 点「进入战斗」后，本关转盘方案冻结，界面切到战场

推荐初始方案（教程默认）：

| 效果 | 权重 |
| --- | --- |
| 紧急维修 | 28 |
| 装甲镀层 | 24 |
| 速射强化 | 22 |
| 散射弹幕 | 26 |

### 转动表现

- 使用圆锥渐变绘制转盘，配色走战场风（红、青、琥珀），不要复制幸运转盘的金币橙。
- 指针固定在 12 点钟。
- 旋转 3–5 圈后停在目标扇区中心角。
- 结果用一行战报写清数值：「转盘停在「装甲镀层」，护甲 +28。」
- 转盘常驻在战场右侧或下方缩略，不必每次都盖住全屏；次数 ≥ 1 时高亮。

### 效果目录

共 **18 种**扇区，分四类。开局只能用 4 种基础效果；其余按关卡和 Boss 永久解锁，下次开局仍可用。

下表「Lv1」是未养成时的数值。标了「可升级」的 10 种可在机库花金币升到 Lv3，详见后文养成。

#### 生存（4）

| --- | --- | --- | --- | --- | --- |
| `repair` | 紧急维修 | 开局 | 回复 22 生命；满血时改为 10 护甲 | 瞬间 | 是 |
| `armor` | 装甲镀层 | 开局 | 获得 28 护甲（可叠加，封顶见养成） | 持续到被打掉 | 是 |
| `aegis` | 相位护盾 | 第 1 关 Boss | 完全无敌，期间仍可开火 | 1.8s | 是 |
| `regen` | 再生立场 | 第 1 关 Boss | 每 0.5s 回复 3 生命，共 6 跳 | 3.0s | 否 |

| `cluster` | 集束炸弹 | 第 2 关 Boss | 在锁定目标处爆炸，半径 18 内敌机 36 伤害 | 瞬间 | 否 |

#### 节奏与支援（4）

| id | 名称 | 解锁 | Lv1 效果 | 时长 | 可升级 |
| --- | --- | --- | --- | --- | --- |
| `time-dilation` | 时缓立场 | 第 3 关开场 | 敌机推进与敌弹速度 ×0.45 | 3.2s | 是 |
| `salvage` | 回收协议 | 第 3 关开场 | 击坠能量 ×1.8，漏敌不再掉能量惩罚 | 6.0s | 否 |
| `drone` | 护航无人机 | 第 2 关 Boss | 在左右航道各部署 1 架自动炮台，伤害 5 / 260ms | 8.0s | 否 |
| `bounty` | 打捞协议 | 第 3 关开场 | 本局结算金币 +18%，并立刻获得 12 点能量 | 瞬间 | 否 |

叠层规则：

- 同类持续效果只刷新时长，不无限叠乘。
- `repair` 在满血时转为护甲，数值跟当前升级等级走。
- `purge` / `cluster` 对 Boss 本体有伤害，但不能一键秒杀；Boss 受到范围伤害时按表内数值结算，不再额外吃穿透加成。
- 同时最多保持 3 个持续火力效果（`rapid` / `spread` / `pierce` / `missile` / `laser` / `overclock`）；超出时顶掉剩余时间最短的一个。
- 过载的承伤惩罚与相位护盾同时存在时，护盾期间不受伤，过载伤害加成保留。
- `drone` 炮台不能被敌机摧毁，时间到了自行撤离。
- `bounty` 同一局多次抽中时，金币加成不叠乘，只再给 12 能量。
- `emp` 不清除已有敌弹，只让新弹停产，适合和清屏错开用。

### 组装策略（给关卡设计用）

玩家应明显感到「不是越大越好」，也不是「有次数就立刻转」：

- 把 `repair` 做到 40，Boss 护盾阶段会缺输出窗口。
- 把 `missile` 做到 40，三路杂兵战不如散射或无人机来得稳。
- 第 3 关 Boss 有护盾阶段和激光预报，没有 `pierce` / `purge` / `aegis` / `laser` 会明显吃力。
- 次数囤满 3 次再进 Boss 是合理策略，但前面漏太多敌，基地会先倒。
- `bounty` 适合已经能稳定过关的养成局，不适合残血硬闯。

不要做隐藏惩罚格。如果后期要加「变数」，优先加「双效果扇区」（例如维修量较低但附带一点护甲），而不是空白格。

## 机库养成

养成发生在局外，不进战斗。金币是本游戏自己的补给货币，**不和幸运转盘的金币互通**。

### 什么会跨局保留

| 数据 | 是否保留 | 存储 key |
| --- | --- | --- |
| 最高分 | 是 | `tiny-games:wheel-battle:high-score` |
| 补给金币 | 是 | `tiny-games:wheel-battle:coins` |
| 效果升级等级 | 是 | `tiny-games:wheel-battle:upgrades` |
| 已解锁扇区 | 是 | `tiny-games:wheel-battle:unlocked` |
| 本局转盘方案、生命、能量 | 否 | 每局重开 |

第一次启动：金币 0，4 个开局效果均为 Lv1，其余扇区未解锁。

第一次打过某 Boss / 进入某关后，对应扇区永久解锁。之后新开局可以直接装，不必每局重新打到那一关。

### 何时发金币

只在 **整局结束**（通关胜利或基地被打穿失败）时发一次。本关重开、暂停退出再继续，都不发。

最低保底 25，避免第 1 关早死完全没养成。

| 来源 | 公式 |
| --- | --- |
| 基础出勤 | 40 |
| 击坠 | 击坠数 × 0.4，向下取整 |
| Boss 阶段 | 每跨过 1 个 Boss 阶段 +25 |
| 剩余生命 | 结算时生命 × 0.4，向下取整 |
| 未用转动次数 | 每次 +8 |
| 通关奖励 | 胜利 +80，失败 +0 |
| 漏敌惩罚 | 每漏 1 架 -2 |
| 打捞协议 | 若本局触发过 `bounty`，总金币 ×1.18 后再取整 |

示例：第 1 关 Boss 战死，击坠 18、漏敌 3、剩 20 生命、剩 1 次转动 → 约 `40 + 7 + 25 + 8 + 8 - 6 = 82`。  
三关通关、发挥中等 → 约 200–280。把一个效果从 Lv1 升到 Lv3 需要 180，大约 1 次通关或 2–3 次中途失败。

### 哪些效果能升级

只有 10 种可升级，避免 18 个入口都要养成、玩家不知道先点什么。其余 8 种靠「何时转」体现价值，不靠数值堆高。

升级消费：

| 目标等级 | 费用 | 说明 |
| --- | --- | --- |
| Lv1 → Lv2 | 60 | 新解锁的效果默认 Lv1，不必买 |
| Lv2 → Lv3 | 120 | 满级 |

不能跳级。金币不够时按钮禁用。升级立即生效，下一局整备可见新数值；已经开始的战斗不改。

### 升级数值

| id | Lv1 | Lv2 | Lv3 |
| --- | --- | --- | --- |
| `repair` | 治疗 22 / 溢出护甲 10 | 30 / 14 | 40 / 18 |
| `armor` | +28，护甲上限 80 | +38，上限 90 | +50，上限 100 |
| `aegis` | 1.8s | 2.3s | 3.0s |
| `rapid` | 间隔 110ms，持续 6.5s | 100ms，8s | 90ms，10s |
| `spread` | 侧弹伤害 6，持续 7s | 8，8.5s | 10，10s |
| `pierce` | 8 发，+35% | 11 发，+45% | 14 发，+55% |
| `missile` | 5 枚，伤害 16 | 7 枚，伤害 20 | 9 枚，伤害 24 |
| `overclock` | 伤害 ×1.45，承伤 +20% | ×1.60，承伤 +15% | ×1.80，承伤 +10% |
| `purge` | 清弹 + 范围 24 | 清弹 + 34 | 清弹 + 48 |
| `time-dilation` | 3.2s，速度 ×0.45 | 4.0s，×0.38 | 5.0s，×0.32 |

设计约束：

- 第一局不升级也应能凭时机通关。养成提高容错和分数，不是开门砖。
- 若测试时「满级维修 + 满级护甲」可以无视第 3 关激光，就提高激光伤害，而不是把费用加到买不起。
- 机库要显示「下一局才会生效」，避免玩家以为战斗中途加了数值。

### 机库界面规则

- 入口在整备页顶部：「机库」与「组装」两个页签。
- 机库列出 18 种效果：未解锁灰显并写解锁条件；已解锁显示当前等级和下一档对比。
- 可升级的 10 种有「升级」按钮和费用。
- 不可升级的 8 种标注「靠时机，不提供升级」。
- 金币余额常驻右上角。
- 不提供重置升级、不提供金币购买转动次数。

## 关卡与 Boss

全作 3 关。每关结构固定为：

```txt
整备转盘（战斗外）→ 进入战斗后方案锁定
→ 波次 A（教学/热身）→ 波次 B（混编）→ 波次 C（三路压迫）→ Boss
```

波次之间不切屏。HUD 会预报下一波：航道、敌种、大约到达时间。Boss 入场前清掉残余小兵，给 1.2 秒预警。

预报是给「何时转动」用的信息，不是让玩家去走位。

### 第 1 关 · 流星航线

- 目标：教会能量兑换次数、次数可存、在波次到来前转动。
- 时长目标：90–110 秒进入 Boss。
- 前半只走中路，后半开始出现左右路，促使玩家理解散射的价值。
- 精英机在波次 C 出现 1 架。

**Boss：铁甲甲虫**

- 生命 720，停在中路前方，不需要玩家绕背。
- 阶段 1（100%–55%）：中路三连射，夹杂少量左右弹。护甲和维修足够撑。
- 阶段 2（55%–0%）：预报 1.5 秒后砸下一波弹雨。这是第一次明确的「现在该转」窗口。
- 挑战点：若把 3 次机会都在小兵阶段花光，弹雨会直接打残基地。
- 击败奖励：永久解锁 `aegis`、`pierce`、`regen`。

### 第 2 关 · 裂空峡谷

- 目标：强迫使用三路覆盖，并学会把次数留到双目标阶段。
- 进入本关整备时永久解锁 `overclock`、`bulkhead`、`emp`。
- 炮艇更多，左右路同时推进，没有散射 / 导弹 / 无人机时漏敌会明显增加。

**Boss：双子无人机**

- 生命：左机 420 + 右机 420，必须都击破。
- 两机分列左右航道，交替开火：一边扇形弹，一边对基地瞄准弹。
- 当其中一架被击破，另一架进入狂暴（射速 +40%，推进更靠前）。
- 挑战点：火力偏科会让残机漏伤爆表；在双机齐在时转散射 / 导弹，比打掉一台再转更划算。
- 击败奖励：永久解锁 `missile`、`purge`、`cluster`、`drone`。

### 第 3 关 · 赤红母舰

- 目标：终局考试。杂兵少但准，精英机带护盾。
- 开场即永久解锁 `time-dilation`、`salvage`、`laser`、`bounty`，并强制回到整备界面重装转盘。

**Boss：赤红母舰**

- 生命 1600，三阶段，具有真实威胁。每个阶段都有可读的预报，而不是靠手速躲开。

| 阶段 | 生命区间 | 机制 | 建议窗口 |
| --- | --- | --- | --- |
| 装甲甲板 | 100%–70% | 正面护盾吸收 50% 普通弹伤害 | 开阶段立刻转穿甲 / 过载 / 切割激光 |
| 弹幕核心 | 70%–35% | 预报 2 秒后环形弹 + 追踪弹 | 预报出现时转护盾 / 清屏 / 时缓 / EMP |
| 过载核心 | 35%–0% | 召唤 2 架精英护卫，激光扫射前有 1.2 秒充能条 | 充能条亮起再转；无人机和集束可清护卫 |

失败常见原因应可被「方案 + 时机」对策：

- 被弹幕或激光打穿 → 次数留得够，且轮盘里有 `aegis` / `purge` / `time-dilation`
- 打不穿护盾 → 战前装了 `pierce` / `overclock`，并在甲板阶段就转
- 残血却把维修浪费在满血波次 → 次数管理失败
- 左右路漏敌太多 → 战前散射 / 导弹权重不够

击败后进入通关结算，不循环无尽模式（可在后续版本加无尽）。

## UI 结构

复用 `GameLayout`：返回首页、标题、说明、重新开始。游戏内部再分三块。

### 游戏舞台

1. **机库页签（局外）**：金币余额、18 种效果图鉴、10 种可升级项的升级按钮。
2. **整备页签（战斗外）**：左侧已解锁效果，右侧转盘预览与滑杆，底部「进入战斗」。未解锁效果不可加入。
3. **战场 Canvas**：固定战机、三航道敌机、子弹、Boss、无人机（若生效）、背景。提供 `aria-label="转盘大作战战场"`，并用旁路文本同步生命、能量、转动次数、关卡、金币。
4. **HUD**：生命、护甲、能量、转动次数 `n/3`、当前关卡、击坠分、进行中的效果标签、下一波 / Boss 技能预报。
5. **转盘模块（战斗中常驻）**：缩小的转盘 + 「转动」大按钮。次数 ≥ 1 时高亮。按下后播放旋转，不打开新的组装或机库界面。
6. **结算面板**：胜利或失败，展示分数、最高分、本局金币明细、转动次数使用记录、漏敌数。确认后回机库。

### 操作按钮

- 进入战斗 / 下一关整备
- 转动转盘（次数 ≥ 1）
- 加入 / 移除扇区（仅组装页签）
- 平均分配、推荐方案（仅组装页签）
- 升级效果（仅机库页签，且该效果已解锁、未满级、金币足够）
- 暂停（战斗中，打开后冻结循环）
- 重新开始（结束本局并进入结算，会发金币）

战斗中不出现组装滑杆和升级按钮。暂停菜单里可以查看当前方案和效果等级，但不能改、不能花金币。

### 统计信息

- 当前分 / 最高分
- 补给金币 / 本局预计金币
- 击坠数 / 漏敌数
- 转动次数获得 / 使用
- 受到伤害总量
- Boss 用时

### 说明侧栏

- 3 关与 Boss 一句话
- 18 种扇区效果列表，可升级的标注等级
- 操作说明：战斗中只需按「转动」；`Space` 也可
- 强调：扇区大小就是概率，转动时机决定这发强化打在哪一段；金币只在局后升级效果

### 窄屏

- 战场保持 3:4 画板，宽度吃满，HUD 叠在画板上缘。
- 整备面板改为上下结构：机库与组装分页，先转盘预览，再滑杆或升级列表。
- 战斗中转盘缩在底部，转动按钮最小点击区域 44px。
- 不提供虚拟摇杆，因为没有走位。

## 实现分期

只做策划时不要一次写完整战斗。建议实现按五个可玩切片交付：

1. **机库 + 整备 + 转盘原型**：18 种图鉴可浏览，4–7 格可组装，能转出效果文本；进入战斗后方案锁定。金币升级可先做静态按钮。
2. **自动空战沙盒**：固定战机、三航道敌机、自动锁定开火、能量条、漏敌扣血。没有走位。
3. **次数叠加接转盘**：满能量 +1 次机会，可存到 3；玩家选时机转动，效果按当前升级等级改射速 / 护甲 / 生命。
4. **三关 Boss**：铁甲甲虫 → 双子无人机 → 赤红母舰，全部带预报窗口，补结算与最高分。
5. **局后养成闭环**：结算发金币，机库升级写入 localStorage，解锁永久保留。

每一片都应能独立打开页面玩，而不是最后才拼起来。
